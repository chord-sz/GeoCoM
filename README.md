# GeoCoM

Official repository for **Warp-free Cross-view Geo-localization via Feature-space Consensus Mining** (ECCV 2026).

**Zhuo Song, Lian Xu, Runqing Jiang, Yongjian Zhang, Kunhong Li, Ye Zhang, Yulan Guo**

[Paper](https://arxiv.org/abs/2608.09321) · [PDF](https://arxiv.org/pdf/2608.09321) · [GitHub](https://github.com/chord-sz/GeoCoM)

## Overview

GeoCoM is a cross-view geo-localization framework that learns semantic consensus between street-level and satellite images directly in feature space, without explicit geometric warping. During training, an auxiliary joint-view pathway provides a consensus representation, while shared global pattern probes and a consensus-mediated contrastive objective align the single-view embeddings for retrieval.
